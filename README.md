# Mizanur Rahman — GitHub Pages Portfolio

A responsive, single-page cybersecurity portfolio built with plain HTML, CSS and JavaScript.

## Preview locally
Open `index.html` in a browser. No build tools or package installation are required.

## Publish with GitHub Pages
1. Create a public GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait for the deployment. Your site will be available at `https://YOUR-USERNAME.github.io/`.

## Personalise before publishing
Search the files and update:
- `YOUR_EMAIL@example.com` with your professional email address.
- Social profile links in the Contact section.
- The generic GitHub project links with your actual repository URLs.
- Experience descriptions with your accurate duties and dates.
- Certificate entries with credential verification links.
- Add your profile photo and CV if you want them displayed/downloadable.

## Suggested additions
